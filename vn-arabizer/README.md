# VN Arabizer — معرّب الروايات المرئية

برنامج لتعريب الروايات المرئية (Visual Novels) بدون أن تخرب اللعبة.

## ما يميّزه عن Translator++

- **لا يترجم أسماء الملفات ولا الأكواد.** يقرأ سكربت اللعبة ويأخذ فقط الحوار والاختيارات وأسماء الشخصيات ونصوص الواجهة. أسماء الصور مثل `eileen happy.png` والمتغيرات والـ labels لا تصل للمترجم أصلاً.
- **يحمي الوسوم** مثل `{b}` و`{w}` و`[player]`، ويفحص كل سطر بعد الترجمة. السطر الذي فيه خطأ لا يُكتب في اللعبة.
- **لا يعدّل ملفات اللعبة الأصلية.** يضيف ملفات جديدة فقط، وزر «إزالة التعريب» يرجع اللعبة كما كانت.
- **العربية تشتغل داخل اللعبة:** اتجاه من اليمين لليسار، حروف متصلة، وخط عربي يُركَّب تلقائياً.
- **ترجمة بدون إنترنت** بنموذج NLLB-200: خاصة بالكامل، ولا حدود لعدد الأسطر.

## المحركات المدعومة

| المحرك | الحالة |

## طريقة الاستخدام

1. **فتح لعبة:** اختر المجلد الرئيسي للعبة (الذي فيه مجلد `game`).
2. **① استخراج النصوص:** يحدث تلقائياً أول مرة.
3. اختر المترجم:
   - **NLLB-200 (بدون إنترنت):** اضغط «تنزيل النموذج» مرة واحدة، والموصى به 1.3B.
     لتشغيله على كرت الشاشة NVIDIA: الإعدادات ← «تنزيل دعم كرت الشاشة».
   - **Google:** مجاني ويحتاج إنترنت. يرسل الطلبات ببطء وبكميات قليلة حتى لا يحظرك. Google يرى النص والـ IP.
   - **DeepL:** يحتاج مفتاح API خاص بك.
4. **② ترجمة:** يمكنك تعديل أي سطر بيدك بالضغط عليه مرتين.
5. **قاموس الأسماء:** اكتب اسم كل شخصية بالعربي مرة واحدة، فيُستخدم نفسه في كل الحوارات.
6. **③ تطبيق على اللعبة** ثم **▶ تشغيل اللعبة**.

### وضع التخفي
من الإعدادات. عند تفعيله لا يُحفظ أي مشروع أو سجل على القرص، وكل شيء يبقى في الذاكرة ويُمسح عند الإغلاق. البرنامج نفسه لا يرسل أي بيانات أو إحصائيات لأي جهة.

## ما الذي يُضاف لمجلد اللعبة (Ren'Py)

```
game/zz_vnarabizer.rpy                   إعدادات: RTL، الخط، اللغة، جدول الحوار
game/vnarabizer/say.json                 ترجمة الحوار والاختيارات
game/vnarabizer/VNArabic-*.ttf           الخط العربي (رخصة OFL)
game/tl/arabic/vnarabizer_strings.rpy    نصوص الواجهة وأسماء الشخصيات
```

## ما الذي يتغيّر في لعبة RPG Maker MV/MZ

- **النصوص المترجمة:** الرسائل والاختيارات وأسماء المتكلمين، وأسماء وأوصاف الشخصيات والأدوات والمهارات والحالات، ومصطلحات النظام، وأسماء الخرائط.
- **ما لا يُلمس أبداً:** الأكواد (Script)، أوامر الإضافات، الملاحظات (note)، التعليقات، وأسماء الصور والأصوات.
- **الرموز:** رموز مثل `\V[1]` و`\N[2]` و`\C[3]` و`\I[64]` تبقى كما هي في مكانها.
- **تقسيم الأسطر:** الرسالة المترجمة تُقسَّم من جديد حسب عرض نافذة الرسائل، مع حساب مساحة صورة الوجه إن وُجدت.
- **إضافة `VNArabizer_RTL`:**
  - **MV:** تكتب الرسائل من اليمين لليسار بحروف متصلة، مع بقاء تأثير الكتابة حرفاً حرفاً والألوان والأيقونات.
  - **MZ:** يستخدم دعم العربية الموجود أصلاً في المحرك.
  - في الاثنين: تضيف الخط العربي، وتحاذي القوائم لليمين.
- **النسخ الاحتياطي:** الملفات الأصلية تُنسخ إلى `vnarabizer_backup` قبل أي تعديل، و«إزالة التعريب» يرجعها كما كانت تماماً.

## ما الذي يتغيّر في ألعاب Twine (HTML)

- **ما يُترجم:** نص المقاطع (passages) سطراً سطراً، ونصوص الروابط، ونصوص أزرار الروابط مثل `<<link "...">>` و`<<button "...">>` و`(link-goto: "...")`.
- **ما لا يُلمس أبداً:** الأكواد مثل `<<if>>` و`<<set>>` و`(set:)`، والمتغيرات مثل `$gold`، ووسوم HTML، والتعليقات، ومقاطع السكربت والتنسيق.
- **أسماء المقاطع التي تشير لها الروابط لا تتغير أبداً،** فالرابط `[[Go to town|Town]]` يصبح `[[اذهب للمدينة|Town]]`.
- **العربية:** تُضاف للملف طبقة تنسيق تجعل النص من اليمين لليسار بخط عربي، والخط مدمج داخل الملف نفسه.
- **النسخ الاحتياطي:** نسخة من ملف HTML الأصلي في `vnarabizer_backup`، و«إزالة التعريب» يرجعه كما كان.
- **حدود:** النصوص المكتوبة داخل JavaScript للقصة لا تُترجم.

## سطر الأوامر

```
vnarabizer-cli.exe translate "D:\Games\MyVN" --engine nllb --source ja --apply
vnarabizer-cli.exe remove "D:\Games\MyVN"
vnarabizer-cli.exe download-model nllb-1.3b
```

## للمطورين

```
pip install -r requirements.txt pytest
python -m pytest tests
python -m vnarabizer                     # تشغيل الواجهة
pyinstaller packaging/vnarabizer.spec    # بناء البرنامج
```

ملف التثبيت `VNArabizer-Setup-*.exe` يُبنى تلقائياً على GitHub Actions، ويمكن تنزيله من صفحة Actions ← آخر تشغيل ← Artifacts.

## الرخص

- خط VN Arabic مبني من Noto Sans Arabic وNoto Sans، برخصة SIL OFL 1.1.
- نموذج NLLB-200 من Meta برخصة CC-BY-NC 4.0: للاستخدام غير التجاري.
- استخدم البرنامج على ألعاب تملكها، وانشر ملفات التعريب فقط وليس اللعبة كاملة.
